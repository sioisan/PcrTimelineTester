# PcrTimelineTester

公主连结公会战调轴工具。载入 PCRCalculator 导出的五人阵容和 Boss 时间轴（`.xlsx`），通过摸轴器的 HTTP `/simulate` 接口比较整场期望伤害。可在 Windows 图形界面或命令行运行。

## 从界面开始

1. 打开 `PcrTimelineTester.exe`，点「打开时间轴…」选择 Excel。使用源码时，安装 Python 3.10+、`httpx` 和 `openpyxl`，在项目目录运行 `.\run.bat gui`。
2. 在左侧「通用设置」填写 PCRCalculator 安装目录和端口。勾选「开始搜索时自动启动摸轴器」可自动启动本地算器，默认端口为 8080。该端口已有算器时会直接复用。
3. 选择优化模式，在「模式参数」调整后点开始。右侧可切换「时间轴」「日志」「结果」。拖动结果表头分隔线调整列宽，超出窗口的部分可横向滚动。点右下角时钟切换白天或黑夜主题，下次启动会沿用。

## 选择优化模式

| 想做什么 | 模式 | 主要输出 |
| --- | --- | --- |
| 微调已有手动轴的 UB 帧，尝试邻近两刀联动或同帧换序 | 逐帧搜索 `frame` | `调帧结果.xlsx` |
| 改变循环，寻找多开或少开 UB 后伤害更高的打法 | 循环搜索 `cycle` | `循环搜索结果.xlsx` |
| 交叉、变异五名角色的语义 UB 序列 | 语义 GA `ga` | `优化结果.xlsx` |
| 从语义轴逐步尝试改刀，允许暂时掉伤 | 退火 `anneal` | `退火结果.xlsx` |
| 在候选池中排完符合分组条件的五人队，比较 AUTO / SET | 阵容搜索 `roster` | `阵容结果.xlsx` |
| 固定队伍，逐刀选择 AUTO / SET | 0押轴 `zero` | `0押结果.xlsx`（原轴附操作摘要） |

**循环搜索**会根据实际 TP 到账、技能命中和 UB 出手帧生成候选，并在下一层重读战斗事件。只有阵容和 Boss 时也可以从自动开场起轴。默认搜索 4 层，每层保留 4 个分支，每个分支最多试 64 个候选。想连续改更多步可增加「搜索层数」，想同时保留更多打法可增加「保留分支」。

循环搜索的主结果按整场期望伤害选取。找到比基线多开 UB 的打法时，会从中保留伤害最高和刀数最多的轴，额外文件名形如 `45发分支.xlsx`。相同结果只导出一份。多种子运行时，伤害取均值，实际刀数按首个种子统计。

**阵容搜索**的分组人数是下限。设为「至少 2 人」时，该组可以上 2 至 5 人，只要候选池和其他分组也允许。组间可以重叠。默认每队比较 32 种组合，关闭「每队试 32 种」后只测全 SET。结果按真实站位显示，`O` 表示 SET，`X` 表示 AUTO，最多保留 100 支队伍。

导入黎明界关卡后，阵容搜索会按角色可穿的 EX 类别配装。武器为 20 贯通，防具为 12 贯通，首饰为 8% 攻击。满属性和原轴练度都使用这套装备，结果表保存最优队伍的配装和首个种子的实放 UB 帧。

## 命令行与结果

在项目目录运行以下命令。算器需已启动，非默认地址用 `--endpoint` 指定。

```powershell
.\run.bat inspect 轴.xlsx
.\run.bat probe 轴.xlsx
.\run.bat tune 轴.xlsx --passes 2
.\run.bat tune 轴.xlsx --mode cycle --set depth=6 --set width=4 --set candidates=96
.\run.bat modes
.\run.bat resume "runs\运行目录名"
```

`--passes` 是逐帧搜索的轮数。每轮使用上一轮的最优帧。`modes` 可列出各模式的参数和默认值。

每次运行单独保存配置、日志、状态和报告。GUI 默认在原轴旁的 `runs\` 下生成结果，正常结束后自动载入结果表。中途停止会保存 `state.json`，可点「续跑…」选择运行目录继续。程序设置、图标缓存和崩溃日志位于 `%LOCALAPPDATA%\PcrTimelineTester\`。
